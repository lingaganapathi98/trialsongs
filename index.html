      Setup & playback help

      Set API_KEY and FOLDER_ID at the top of this page’s script. Enable Google Drive API v3 in Google Cloud, create an API key restricted to this website’s HTTP referrers and the Google Drive API, and share the folder and songs as “Anyone with the link — Viewer.” See README.md for full instructions.

      Playback uses the documented Drive API media endpoint. If a song fails, open its Drive link, check public sharing and download permission, or upload an MP3/AAC version supported by your browser. Drive download quotas and organization sharing policies can also block playback. No sign-in is requested.
